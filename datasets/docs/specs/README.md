# Specifications and implementation TODOs

This directory holds the repository's implementation specifications and their
verification-oriented TODOs. Files are retained as a record of the decision
and scope that produced a change; an older TODO may describe a completed or
superseded implementation, so confirm its assumptions against the current
source of truth before acting on it.

Operational policy and validation guidance remain in `../`, notably
`../datasets-affiliation-records-20260728.md`.
